1. 데이터 캐싱과 commit의 의미
    1-1. 파일에 저장된 데이터를 참조할 경우 메모리로 캐싱 -> 파일에 저장된 데이터는 대용량이라고 가정합니다. (참조 -> 검색)
        => 즉, 참조할 경우 연결리스트에 올리는 작업을 해라 (캐싱)
        => 대용량의 데이터를 전부 ram에 추가하는 작업? -> 효율적인 실행이 아님
    1-2. 메모리에 로드된 정보를 수정한 경우 이는 파일로 저장된 것이 아니므로 영속성을 가지지 못함
        => 영속성을 가지려면 2차 메모리에 저장해야 합니다.
    1-3. 1차 메모리에 저장된 데이터와 2차 메모리에 저장된 내용을 동기화 하는 것
        => 1차 메모리 수정된 내용을 2차 메모리에 반영하는 것 - commit 입니다.


2. 구조는 메모리상에 존재하고 참조가 들어왔을 떄 파일에서 불러와서 대상을 가져오는 것이 캐싱입니다.
    => 캐싱된 것을 저장 -> 파일에 위치를 찾아서 오버라이트
    => 수정된 것만 저장할 수 있습니다.
