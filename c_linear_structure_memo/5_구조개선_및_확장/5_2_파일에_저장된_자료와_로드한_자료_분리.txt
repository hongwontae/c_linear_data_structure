1. 파일로 저장한 자료와 로드한 자료 분리
    1-1 파일은 논리적으로 연속된 메모리 공간이며 배열처럼 사용 가능
    1-2. 구조체 전체 자료는 파일로 저장하고 조건 검색에 따라 선택한 자료만 메모리로 로드
    1-3. 인덱스 역시 파일로 분리하되 전수 메모리에 로드


2. 메모리 수준 편집 및 파일 반영 분리
    2-1. 새로 추가하는 데이터는 파일로 즉시 저장
    2-2. 기존 데이터 검색 후 편집 시 편집한 내용은 메모리 상에서만 저장하고 출력
    2-3. 메모리 상에 존재하는 데이터와 실제 파일 상 내용이 일치하도록 동기화하는 기능 분리
