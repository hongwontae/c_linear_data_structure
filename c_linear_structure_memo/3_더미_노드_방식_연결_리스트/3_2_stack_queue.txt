1. Stack 구조
    1-1. 데이터 입/출구가 하나뿐인 선형구조입니다.
    1-2. Last in First Out 구조입니다.
    1-3. 데이터 추가는 Push, 데이터 꺼내기 Pop이라고 부릅니다.


2. Queue 구조
    2-1. 데이터 입/출구가 분리된 선형 구조입니다.
    2-2. First in First Out 구조입니다.
    2-3. 데이터 추가는 Enquque(Put, Insertion), 제거는 Dequeue(Get, Deletion)이라고 합니다.
    2-4. Head/Tail을 Front/Rear라고도 합니다.
    2-5. 순차적인 처리가 필요할 떄 주로 queue를 많이 사용합니다.


3. Stack Code
    3-1. 데이터를 추가하는 곳과 나가는 곳이 일치해야 합니다.
    3-2. push_node는 추가되는 데이터가 가장 처음에 위치해야 합니다.
        => 기존의 첫 번쨰 노드는 그 다음이 됩니다.
    3-3. 데이터를 초기화합니다.
    3-3. 노드의 포인터를 정리해야 합니다. -> 4개를 해야 합니다.
        => head_node와 new_node를 정리합니다 / head_node의 다음 요소, new_node의 이전 주소 정리
        => new_node와 기존 head_node->p_next를 정리합니다. / new_node의 다음 요소, head_node->p_next의 이전 주소 정리
    
    3-4. pop_node()는 head_node의 첫 번째를 삭제하면 됩니다. -> push할 떄 첫 번쨰에 오게 했습니다.
        => 일단 dummy만 존재할 떄 처리를 합니다.
        => pop할 노드를 찾습니다.
        => 노드의 포인터를 정리해야 합니다. -> 2개를 해야 합니다.
            => head_node의 다음 주소를 pop의 다음 주소로
            => pop의 다음 노드의 이전 주소를 pop의 이전 주소로 (사실상 헤드 노드)


4. Queue Code
    4-1. 데이터를 추가하는 곳과 나가는 곳은 달라야 합니다.
    4-2. 데이터를 추가하는 enqueue는 add_new_node() 함수를 호출하여 사용합니다.
        => tail_node에 추가됩니다. -> 맨 뒤에서 추가됩니다.
    4-3. 데이터를 삭제하는 dequeue는 pop_node() 함수를 호출하여 사용합니다.
        => head_node부터 삭제됩니다. -> 순차적으로 처리됩니다. -> clear_node의 로직과 다를게 없습니다.
