1. 2중 연결 리스트
    => 하나의 노드가 두 개의 포인터를 갖는 연결 리스트를 의미합니다.
    => 싱글 연결 리스트는 노드 하나가 다음 노드의 주소를 가지고 있습니다.
    => 2중 연결 리스트는 노드 하나가 이전의 노드의 주소와 다음의 노드의 주소를 갖고 있습니다.
    => Dummy_Head, Dummy_Tati로 간결한 구조로 만들 수 있습니다.
    => 데이터를 추가할 떄는 Dummy_Tail 앞에 추가하면 됩니다.


2. 2중 연결 리스트 구현 시 고려사항
    2-1. 더미 헤드/테일 노드를 추가
    2-2. head.next == &tail이면 Empty입니다.
    2-3. 노드가 하나만 있어도 prev, next -> 포인터는 결코 null이 될 수 없습니다.


3. 2중 연결 리스트 노드 추가
    3-1. 추가할 노드의 prev, next 정보를 먼저 설정해야 합니다.
    3-2. 노드 삽입이 일어나는 지점의 prev 노드에 접근합니다. (반대로 next 노드를 찾아도 상관없습니다.)
    3-3. 첫 번쨰로 추가되는 노드와 이후 추가되는 방식은 구분되어야 합니다.


4. 2중 연결 리스트 노드 삭제
    => 전 노드를 찾을 필요가 없습니다.
    => 노드에 전의 노드의 주소도 있기 때문입니다.
