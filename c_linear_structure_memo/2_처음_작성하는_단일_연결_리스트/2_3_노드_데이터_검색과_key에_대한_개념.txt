1. 노드 데이터 검색과 Key
    1-1. Key라는 것은 노드 하나를 유일하게 식별할 수 있는 값입니다.
    1-2. 전체 데이터에서 절대로 중복되는 것이 없어야 하며 정렬이나 검색의 기준이 됩니다.
    1-3. Key 중복 방지는 데이터를 추가하는 시점에서 확인해야 합니다.
        => 데이터 추가와 데이터 검색 중 속도가 중요한 시점은 검색 시점입니다.
        => 대체로 데이터 추가는 사용자 입력을 받아서 처리합니다. -> 구조를 손상시키지 않아야 하는 구조를 받아야 함 -> 무결성 검증
    1-4. 선형 자료 구조의 검색은 일치하는 데이터를 찾을 때까지 확인하는 방법입니다. -> 비효율적
