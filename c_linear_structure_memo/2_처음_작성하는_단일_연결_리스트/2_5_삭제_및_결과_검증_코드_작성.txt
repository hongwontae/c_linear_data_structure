1. 삭제할 떄 필요한 정보는 현재 삭제할 노드와 이전 노드를 알아야 합니다.


2. 기본값을 정할 떄 현재 삭제할 노드 -> global_head_node / 이전 노드 -> NULL
    => 자료구조에서 첫 노드만 존재하는 상황을 고려하는 것입니다.


3. while문으로 모든 노드를 검사한다는 조건을 사용합니다.


4. while 내 if문으로 strcmp을 사용해서 일치하는 케이스와 일치하지 않는 케이스로 나눕니다.


5. 만약 일치하지 않는다면
    => 현재 삭제할 노드를 다음 노드로 바꿉니다.
    => 이전 노드는 현재 노드로 바꿉니다.


6. 만약 일치한다면
    => 만약 첫 노드를 삭제해야 한다면 prev가 NULL이 아니여야 합니다. -> while의 분기를 한 번도 돌지 않아야 합니다.
    => 또한 strcmp가 true여야 합니다.
    => 이 때는 단순하게 global_node에 현재 노드->p_next인 NULL을 대입하고 현재 노드를 free()합니다.
    => 그리고 return;


7. 만약 일치하고 두 번쨰 이후 노드인 경우
    => 일치하지 않을 case에 의해서 prev과 current는 정확하게 들어왔습니다.
    => 이전 값의 p_next가 current의 p_next 값을 가리키고 return 합니다.
