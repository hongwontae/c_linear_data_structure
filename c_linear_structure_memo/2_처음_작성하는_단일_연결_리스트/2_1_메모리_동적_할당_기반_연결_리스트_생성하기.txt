1. 헤드 노드에 대한 포인터
    1-1. 리스트의 처음에 해당하는 노드를 가리키는 포인터를 사용하는 방식
    1-2. 데이터 추가 삭제 시 헤드 노드에 대한 포인터를 항상 고려해야 합니다.
    1-3. 가장 단순한 구조입니다.


2. 메모리 동적 할당 기반 연결 리스트
    2-1. 구조체가 저장될 수 있는 메모리 크기를 malloc() 함수로 동적 할당합니다.
    2-2. 연결 리스트를 구성하는 모든 노드는 HEAP 영역 메모리를 사용해야 합니다.


3. 싱글 링크드 리스트를 구현할 떄 헤드 포인터를 지역 변수로 선언 | 전역 변수로 선언 -> 고민해봐야 합니다.
    => 전역변수의 사용은 최대한 자제하는 게 좋습니다.
    => 현 프로젝트에서는 헤드 포인터를 전역 변수로 선언할 예정입니다.


4. 연결 리스트 코딩 순서
    4-1. 전체 리스트 출력 함수 작성
    4-2. 새 노드 추가 함수 작성 (개발에 앞서 절차를 정확히 글로 기술)
    4-3. 전체 리스트 삭제 함수 작성
    4-4. 각 함수를 작성할 때마다 main()에서 테스트 코드를 실행합니다.
    4-5. ** 키보드로 코딩하기 전에 글이나 그림으로 판단을 잡고 가야 합니다. ** -> 현재 내가 안하고 있는거 -> 실천하자


5. 새 노드 추가하기
    5-1. 자료구조를 구성하기 전에 헤드 포인터가 NULL인지 확인합니다. -> if(ptr == NULL) {} else {}...
    5-2. 새 노드를 추가할 떄 새로운 노드가 들어갈 수 있는 포인트는 head와 tail입니다.
        => 해드에 새 노드를 추가하는게 더 간단합니다.


6. 작업 완료 후 모든 노드 free() 작업
    => 모든 연결 리스트 노드들을 head_node를 통해서 삭제해야 합니다.
    => 이 떄 단순하게 head_node를 free()를 하면 다음 주소를 찾지 못합니다.
    => back_up이라는 포인터 변수를 두어서 free 전에 삭제할 노드가 가리키는 다음 노드 주소를 가져야 합니다.
    => 그런 다음 삭제할 노드를 free()합니다.
    => 그리고 head_node는 back_up을 받아서 다음 노드를 가리키게 만듭니다.
    => 이 때 back_up이 계속 찾아가서 null이 되고 이를 할당받게되면 아무것도 없습니다. -> 이 떄 종료해야 합니다. -> while의 조건문
