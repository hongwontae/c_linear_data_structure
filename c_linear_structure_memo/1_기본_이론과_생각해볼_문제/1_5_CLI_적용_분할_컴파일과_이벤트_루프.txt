1. CLI UI 적용 - 분할 컴파일
    1-1. 화면 출력 코드, 자료구조 코드 등을 개별 .c 파일로 분할합니다.
    1-2. .c파일 내부에서 전역변수 사용 시 해당 파일 스코프에서만 접근할 수 있도록 정적 선언해야 합니다.
    1-3. 코드 분할 이유 -> 유지보수/ 오류 최소화


2. CLU 적용 이벤트 루프
    2-1. main() 함수에서 사용자 인터페이스 출력 및 사용자 입력을 반복하는 구조을 의미합니다.
    2-2. 보통 메뉴출력과 사용자 선택을 확인
    2-3. 메뉴 선택에 따라 기능을 수행합니다.
    2-4. 대부분의 응용 프로그럄이 채택하는 일반적 구조입니다.
    2-5. while문으로 이벤트를 확인하고 이벤트에 해당하는 함수를 실행하는 구조를 이벤트 루프라고 합니다.
